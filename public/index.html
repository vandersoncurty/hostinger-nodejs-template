Sua aplicação Node.js está no ar

Esqueleto moderno com Express, folha de estilo e JavaScript, pronto para deploy na Hostinger.

Sobre este esqueleto

  • Node.js + Express — servidor web leve e rápido.
  • Pacotes atualizados — dependências travadas via package-lock.json.
  • HTML semântico — landmarks header, nav, main e footer.
  • CSS moderno — variáveis CSS, layout responsivo e modo escuro.
  • JavaScript sem inline — interatividade via addEventListener.

Deploy na Hostinger

  1. Envie os arquivos (exceto node_modules) via FTP ou Gerenciador de Arquivos da Hostinger.
  2. Copie .env.example para .env e defina a PORT.
  3. Na hPanel, acesse Hosting → Node.js → Setup Node.js App.
  4. Escolha a versão do Node.js, defina server.js como arquivo de inicialização e a porta.
  5. Execute npm install e inicie a aplicação.
